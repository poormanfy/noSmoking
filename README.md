# 🚭 NoSmoking · 桌面戒烟记录小插件

一个常驻桌面、精致小巧的戒烟助手。无窗口边框、默认置顶、可拖到屏幕任意位置，最小化进系统托盘。实时记录你的戒烟成果，用数据激励你坚持下去。

> 基于 **Electron** 构建的原生桌面应用，所有数据保存在本机，无需联网、不收集任何个人信息。

---

## ✨ 功能特性

### 📊 看板
- **实时戒烟计时**：精确到秒的"已坚持多久"，每秒刷新
- **三大多赢指标**：
  - 💰 已省下的钱（按烟价自动计算）
  - 🚬 少抽的烟（支）
  - ⏳ 夺回的生命（小时，可按每支烟折寿分钟数估算）
- **🎯 每日目标**：自定义每日需战胜的烟瘾波数，进度条 + 圆点实时反馈，达标变金
- **健康恢复里程碑**：9 级进度（20 分钟心率恢复 → 1 年心脏病风险减半），达成自动打勾 ✔

### 👊 打卡
- **60 秒烟瘾倒计时**：烟瘾来袭点一下，跟随圆环做 60 秒深呼吸，扛过去即自动记录
- **本周战绩**：统计近 7 天战胜烟瘾次数，保留最近 20 条打卡历史

### 🏆 成就徽章
- **12 枚成就**，覆盖四个维度：
  - 打卡次数：🥊 首胜 → 🔥 十连 → ⚡ 瘾头克星 → 👑 百分斗士
  - 坚持时长：🌅 24 小时 → 📅 首周 → 🌙 满月
  - 少抽数量：🚬 少抽一百 → 🏅 千支斩
  - 省钱金额：💰 百元 → 💎 千元 → 🎯 目标达成者
- 首次解锁弹出 Toast 庆祝提示，徽章墙展示收集进度

### ⚙️ 设置
- 自定义戒烟开始时间、每日吸烟量、烟价、每包支数、每支烟折寿分钟数
- **重新计时**：复吸后可一键重置起点，打卡历史自动保留

### 🪟 桌面体验
- 无边框小窗 + 自定义标题栏，**拖动即移动窗口**
- 📌 一键切换**窗口置顶**
- 关闭按钮最小化到**系统托盘**，托盘图标可唤回 / 退出
- 深色毛玻璃 UI，滚动条 / 卡片 / 渐变文字细节打磨

## 🛠️ 技术栈

| 类别 | 技术 |
| --- | --- |
| 桌面运行时 | Electron 31（主进程 `main.js` + 上下文隔离 `preload.js`） |
| 界面 | 原生 HTML / CSS / JavaScript（无框架、零运行时依赖） |
| 数据持久化 | Electron `userData` 目录写入 JSON |
| 打包分发 | electron-builder（portable 免安装 `.exe`） |

> 无任何前端框架依赖，`renderer` 仅 3 个静态文件，易于阅读与二次改造。

## 🚀 快速开始

### 环境要求
- Windows / macOS / Linux
- Node.js ≥ 18（含 npm）

### 安装与运行

```bash
# 安装依赖
npm install

# 启动桌面小组件
npm start
```

国内网络如安装 Electron 失败，可改用镜像源：

```powershell
# Windows PowerShell
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install --registry=https://registry.npmmirror.com
```

```bash
# macOS / Linux
export ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm install --registry=https://registry.npmmirror.com
```

## 📦 打包为可执行文件

```bash
# 免安装单文件 exe（位于 release/）
npm run dist

npm run pack
```

打包后可将生成的 `.exe` 直接放到桌面双击运行，目标设备无需安装 Node。

## 🧮 核心计算说明

所有数值随戒烟时长与个人设置动态计算（见 `src/renderer/app.js`）：

| 指标 | 公式 |
| --- | --- |
| 少抽的烟 | `戒烟分钟数 ÷ 一天分钟数 × 每天吸烟量` |
| 已省下的钱 | `少抽的烟 ÷ 每包支数 × 每包价格` |
| 夺回的生命 | `少抽的烟 × 每支折寿分钟 ÷ 60`（小时） |

> 默认参数：每天 10 支 / 每包 ¥20 / 每包 20 支 / 每支折寿 11 分钟，均可在「设置」中调整。

## 💾 数据说明

- **保存位置**：系统用户数据目录下的 `no-smoking-state.json`
  - Windows：`%APPDATA%\no-smoking-widget\no-smoking-state.json`
- **内容**：戒烟开始时间、个人参数、打卡记录、徽章解锁状态、置顶偏好
- **隐私**：完全本地存储，应用不联网、不上传任何数据
- **清除**：删除上述 JSON 文件，或在「设置 → 重新设定戒烟时间」即可重新开始

## ⚠️ 常见问题

**Q：安装时 Electron 下载卡住 / 失败？**
A：使用上文的镜像环境变量后重装即可。

**Q：窗口关了怎么找不回来？**
A：程序最小化到系统托盘（任务栏右下角），点击托盘图标即可唤回；要完全退出，右键托盘图标选择「退出」。

**Q：想复吸后重新开始？**
A：打开「设置」，修改戒烟开始时间或点击「重新设定戒烟时间」，历史打卡与已获得徽章会保留。
